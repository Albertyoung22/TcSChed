六大核心亮點與強大優勢

Google OR-Tools CP-SAT 算力

採用國際頂尖限制式滿意解答求解器 (Constraint Programming SAT)，可在數秒鐘內從幾百萬種課表組合中算出最佳零衝突解答。

多元彈性限制條件配置

完美支援「教師不排課時段」、「特定科目避開第8節」、「預排固定課」、「連續授課上限」與「每日科目均勻分散」等規則。

跨班選修與合班/同排同步

專為高中新課綱與多元選修設計！精準處理跨班選修群組、同排課程與虛擬班級（如合班體育、外語選修）的時間軸嚴密同步。

DBF / Excel 雙向完美備份

無縫銜接傳統學校教務系統 DBF 格式數據（claspv_base, no_teach, class），提供一鍵導出 Excel、ZIP 備份與隨時復原快照機制。

教師專屬 Portal 與線上調課

內建響應式 Teacher Portal！教師可透過手機或電腦即時查詢個人課表、尋找代課空堂、並線上提出請假調課申請。

雙軌部署 (Web 雲端 + 桌面版)

採用 Python Flask 與 PyWebView 整合技術，既可作為校園內網 Web 服務，又能一鍵打包為單檔免安裝獨立桌面應用程式。

SYSTEM ARCHITECTURE

先進智慧調度運算架構

舟歌 AI 將學校教務處繁複的排課規則轉換為高維度數學模型。透過 CP-SAT 方程式矩陣化解算，全自動保障教師與班級課表完美契合。

  • 自動消除衝課與空堂浪費
    百分百消除同一教師同節次重複排課、同班級重複排課之絕對衝突。
  • 靈活權重優化 (Soft Constraints)
    可自訂軟性權重，優先滿足教師偏好時段、平均分散主科作業時間。
  • 還原點與快照防護 (Snapshot Restore)
    隨時儲存課表調整快照，支援一鍵還原至任何歷史排課狀態。
